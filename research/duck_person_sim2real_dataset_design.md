# 鸭子真人“认人/手势”Sim2Real 数据集与训练设计（高质量版）

> 目标：最终在真机鸭子（RDK X5 + 头部相机）上做真人识别/手势识别。因此仿真侧从“资产→渲染→标注→模型→推理→控制”都要按真机规格建。

## 1. 关键结论（为什么现在的不够）
- 现在用的是“胶囊+mocap 运动学代理”：可验证控制/状态机，但**外观/几何/相机都不像真机**，模型无法迁移。
- 真实落地需要：**拟真人形资产 + 真机相机模型 + 域随机化 + 标准姿态标注 + COCO 预训练微调 + 端侧评测**。

## 2. 人形资产（第一优先级）
| 层级 | 方案 | 真机价值 |
|---|---|---|
| L0(现) | 胶囊代理 | 只做行为验证 |
| L1 | **关节化低模人形**：肩/肘/腕可动（双段手臂），带头/脸/衣服颜色纹理（MuJoCo menagerie 人体 or 低模 OBJ/glTF 导入，衣服换色） | 姿态/手势几何与真人同构 |
| L2 | 多套“数字人”资产库（不同体型/肤色/衣服/发型），程序化换装 | ReID/检测泛化 |
| L3 | 真人动作重定向（motion capture 驱动）走路/挥手/指点等自然动作 | 动态识别（甩臂、部分遮挡） |

## 3. 相机模型（鸭子真机规格，第二优先级）
- 分辨率/帧率：对齐 RDK X5 头部相机（如 640×480 / 30fps，仿真侧可 320~640 训练+推理都覆盖）；
- 内参：真实 FOV/焦距、镜头畸变（径向）、安装俯仰角（鸭头低，需仰视——已在 headcam 修正）；
- 成像降质：运动模糊、JPEG 压缩噪、白平衡/曝光抖动、散焦；
- 相机位姿随鸭头自由度运动 → 视角多样性（人在画面不同尺度/位置）。

## 4. 标注（免人工，高一致性）
- 检测框：真值几何投影 或 部件色分割（已实现雏形）；
- 2D 人体关键点（COCO-17 子集）：由骨骼关节世界坐标 → **相机投影**（用真实相机模型，不用“猜 FOV”）；缺失/遮挡点标 vis=0（人体姿态标准做法）；
- 身份/ReID：服装颜色/纹理描述子（监督信号免费）；
- 手势标签：骨骼角度真值自动打标（目前按预设，可改为连续角度）。

## 5. 训练调优（第三优先级）
- **预训练 + 微调**：YOLO-pose / RTMPose（COCO 预训练）→ 合成集微调，保留真实泛化；
- 域随机化：光照/背景/衣服/体型/人数（正+负样本）、遮挡；
- 增广：颜色抖动、模糊、透视（与真机相机一致）——增强用 torch/albumentations；
- 评测：留出验证集（不同随机种子位姿），指标 = 检测 mAP + 关键点 PCK/OKS + **任务级手势准确率/响应延迟**（我们更关心任务成功率）；
- 硬例挖掘：Demo 失败的帧回灌训练（model-in-the-loop）；
- 导出：ONNX（+以后 BPU 量化 int8）→ 鸭子端 CPU/BPU 推理，控制频率要求：检测/姿态 ~5–15Hz 足够（50Hz 动作仍是 RL 策略）。

## 6. 落地链路（真机鸭子）
仿真训练(合成RGB) → ONNX → 先在云端仿真“鸭子脑”CPU推理闭环(等价部署) → RDK X5(ONNX Runtime / BPU) 真机相机 → 真人识别+手势 → 动作策略热切换。控制闭环与真机一致，只换“读仿真相机”为“读真机相机”。

## 7. 工作包（建议排期，每包可验收）
- W1 人形资产升级：关节化低模人(肩/肘/腕) + 换装，替换胶囊代理（改 gen_gesture_scene/PoseManager 加肘关节）
- W2 真机相机模型：内参/畸变/噪声/曝光/位姿随机；headcam 用投影真值打标（弃用“色块猜像素”）
- W3 数据集 v2：≥500 帧多样(资产×动作×衣服×光照×距离) + 负样本/遮挡；脚本化再生成
- W4 微调调优：RTMPose/YOLO-pose COCO 预训练→合成微调；增广/超参；评测 PCK+任务成功率；硬例回灌
- W5 端侧验证：ONNX 导出 → 在“鸭子脑”CPU 推理闭环跑 gesture demo（视觉关键点替代 GT）；录 wide 视频验收
- W6（可选真机前置）：RDK X5 试跑 ONNX（CPU），确认 5–15Hz 达标；再谈 BPU 量化

## 8. 说明
- 本设计把“合成数据→微调→端侧推理→控制”当一条可迭代闭环，而不是一次性产物；
- 每次升级都用“任务成功率（手势→动作 是否正确触发）+ 视觉指标”双验收。
