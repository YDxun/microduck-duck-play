## 1. 机器人领域“相关研究”地图（2024–2026 活跃线）

### 1.1 人跟随（RPF）与目标人跟踪（TPT）——最贴近你，已形成 benchmark 群
| 论文 | 年份 | 要点 | 对鸭子的可用性 |
|---|---|---|---|
| Follow-Bench（2509.10796，Hanjing Ye 组） | 2025/2026 v4 | RPF 首个统一规划基准：多场景（目标轨迹/人群/布局）、8 个 planner 重实现、**安全-舒适双指标**、差速轮车上真机验证 | 评测指标可直接借鉴；planner 是轮式，鸭子是双足 RL → 可做“足式版”对照 |
| TPT-Bench（2505.07446） | 2025 | 机器人第一视角（人推小车采集、人手高度）长时目标人跟踪数据集：人群/遮挡/重识别，RGB-D+LiDAR+全景 48 序列 | 数据集思路可搬：**鸭子视角(≈25cm)目前无任何此类数据** |
| Monocular Person Localization under Ego-motion（2503.02916，IROS2025） | 2025 | 移动单目相机下用 4 点人模型联合估计 2D 姿态+3D 位置；已部署到**敏捷四足**做跟随 | 解决“真视觉后怎么从 2D 得距离/方位”：鸭子移动头部/身体时测距的关键方法 |
| Adap-RPF / RPF-Search | 2025 | 拥挤动态遮挡下的人跟随、目标丢失后的找回 | 遮挡重找回是常见坑，可作 L3 难题 |
| TrackVLA++（2510.07134） | 2025 | 语言引导的具身目标跟踪 VLA：Polar-CoT 空间推理 + **Target Identification Memory（门控更新长时目标记忆）**，EVT-Bench SOTA | “描述选目标 + 目标记忆防遮挡跟丢”思想可轻量化搬到鸭子 |

### 1.2 社交导航的奖励与架构——给“鸭子社交运动策略”直接喂配方
| 论文 | 要点 | 可搬内容 |
|---|---|---|
| Proxemics-based reward modeling（2608.12917，2026-08） | 用 **Hall 亲疏距离理论**把每个人建模为径向高斯混合场，在机器人 FOV 内算局部代价 → 稠密、可解释的社交奖励 | **直接做成鸭子的 proxemics 奖励**，再升级为“身份调制”（主人=贴身允许带，陌生人=禁入区更大） |
| HUMA: Think When It Matters（2607.10991，2026-07） | **混合架构**：反应式 RL 策略管常规，**VLM 只在“人进入敏感近距区”等高价值时刻被条件触发**；Social-MP3D/HM3D 提升 20%/3%，个人空间违规显著下降 | 这就是你说的“LLM 管慢、RL 管快”双脑的**已发表版本**——鸭子做“身份+低视角”版并开源，是与它差异化的强基线（可引用来证明方向成立） |
| KinematicRL / Incremental Residual RL / NavThinker | 2026 | 社交导航 sim2real、残差在线学习、动作条件世界模型 | 供后续进阶参考 |

### 1.3 社交机器人：记忆、情绪、陪伴（Agent 层参考）
| 论文 | 要点 | 可搬内容 |
|---|---|---|
| Not Forgotten（2607.24190，2026-07） | 类人头 Kim 的**跨会话个性化 episodic 记忆**（LLM 对话机器人记不住人） | 鸭子“认主人+记得习惯”的记忆模块设计可直接对标；Kim 无运动，鸭子多一层“运动行为随记忆变化” |
| SEAGR 问候机器人（2607.16341，2026-07） | 文化+情绪双调制**问候行为** | L2“认人问候”的行为调制框架 |
| Empathetic social robots（2608.16686，2026-08） | 多模态说话人-听者情绪动态共情 | L2 情绪意图的对话端参考（鸭子语音弱，可弱化） |
| VLM as proxies for social intelligence（2512.07177） | 用 VLM 判断“何时该上前互动”这类非语言线索 | L3 决策触发器的轻量替代 |
| SensHRPS（2512.08518） | 眼动测人机亲疏舒适度 | 说明“个人空间感知”是真问题（真机研究用）；仿真里可用距离+朝向近似 |

### 1.4 低视角/宠物高度的专门研究
- 检索结果：**几乎没有“25cm 级小机器人/宠物高度的认人与社交运动”直接工作**。最接近的是四足跟随（相机在腿以上）与 TPT-Bench（人手高度）。→ 鸭子视角（摄像头离地约 10–20cm、看人主要看到腿/下半身、经常仰视）是明确的空白，也符合“宠物视角陪伴”的产品叙事。

## 2. 我们（鸭子）的新颖性定位（诚实版）

可以主张（写帖/写论文都用这套措辞）：
1. **场景新颖**：首次在 ~25cm 双足小鸭的低视角做“认人+社交运动”全链路（现有：人手高/胸高/腿高的轮式或四足）。
2. **控制新颖**：把“人”写进 **双足 RL 运动策略**（identity/proxemics-conditioned locomotion），而非轮式底盘的导航 planner（Follow-Bench 全是轮式）或手写状态机（你现在的 L1）。
3. **架构组合新颖**：HUMA 式“条件 VLM+RL”首次与“身份/信任分级”结合，且只吃检测/ReID 摘要而非原始像素（省算力、可解释）。
4. **资产新颖**：鸭子第一视角合成人数据集 + mjlab 人-鸭任务 + 评测基准，全开源在 microduck 栈上（生态内无人做认人，见上轮盘点）。

不建议主张：首创“认人/人跟随/proxemics”本身（HRI 领域已有大量先例，Hanjing Ye/Hong Zhang 组就是主力）。**引用他们做 baseline，反而显得你懂行。**

## 3. 推荐方案

### 主推 ★ DuckSoc：低视角“认人 + 身份化社交跟随”全链路（RL 为主菜，Agent 调味）
一句话：**训练一只“认得主人、会守边界、能听懂召唤”的鸭子，全部在云仿真里可复现、可评测、可发布。**

#### 3.1 全链路架构（四层，全部可跑/可训）
```
人(合成代理，主人/访客/陌生人，多样化外观与动作)
   ↓ MuJoCo EGL head_camera 渲染 (320×240, 鸭视角)
[A 感知] 人检测(YOLO11n/RTMD) + SORT跟踪 + 身份(ReID或CLIP“穿红衣服的人”) + 测距(见§3.3)
   ↓ 5–10Hz 异步，输出你的 Detection(label, bbox, range, bearing, identity)
[B 决策·快] Identity-Proxemics RL 策略（50Hz，命令级 [vx,vy,wz]）★你自己训的模型
   ↓ 或 关节级一体化策略（进阶）
[C 决策·慢] 条件 Agent/VLM：只在慢事件触发（召唤指令/陌生人进近距/久坐陪伴/情绪信号）
   ↓ 输出高层意图/任务切换 + 可解释文本链
[D 控制] 官方/自训 61d→14d ONNX 走路/站立/技能策略（热切换，50Hz）
   ↓ 评测：个人空间违规率/召唤成功率/跟随带占比/安全-舒适折衷 + 录像
```

#### 3.2 训练内容（B 层是真正“你训出来的模型”，不是复用走路）
- 任务注册进 mjlab（照 microduck_rl task 写法，可发布到 list-envs）：
  `Mjlab-PersonFollow-Flat-MicroDuck`（跟主人保持带内、正对主人、不闯个人空间）
  `Mjlab-PersonOrbit-Flat-MicroDuck`（陌生人逼近→环形绕行/侧移让路）
  `Mjlab-Summon-Flat-MicroDuck`（召唤→到位→保持）
- 观测：≤N 人 track（bearing/range/range_rate/身份 embed/信任级）+ 自身状态 + 意图 one-hot（延续 61d 契约的“命令槽”，critic 可加人信息）。
- 奖励：**Hall proxemics 高斯混合场（身份调制）**：主人 personal zone 缩小到 0.45m 且跟随带 0.6–0.9m 有奖；陌生人 intimate/personal 禁入（违规扣分）；加朝向人/平滑/少摔/能耗（复用 velocity 正则配方）。
- 先用真值人信息训练（干净信号），再做“课程”：感知输出带噪→ 端到端抗噪。
- 训练规模：4096 env × ~3000–6000 iter，单卡 5090 约 1–3h/任务（参考你已跑通的 4096×6000 走路基线）。

#### 3.3 感知细节（A 层，把“真值”换成“真视觉”的四个关键选择）
1. 数据集：MuJoCo EGL 渲染鸭第一视角合成人（学 microduck-detection-dataset 流程），**打破颜色=身份**：纹理衣服、多体型/肤色/动作、室内 apartment.xml 场景 + 空场、光照/噪声/遮挡/多人重叠/出画。发布 `Microduck-Person-Ego`。
2. 身份：三选一/组合——
   - ReID 小模型（triplet，合成身份上训，top-1 评测）；
   - **CLIP/文本匹配**（“穿红衣服的主人”→embedding，天然支持未注册访客 + 与 Agent 语言连通）；
   - 你 L1 用的“标签/颜色”只保留为 debug 开关。
3. 测距（真视觉后最容易被忽略的坑）：GT 的 range 没了。方案按成本排序：人高先验投影（成人≈1.7m，最简）→ 4 点模型单目定位（2503.02916，IROS2025，适合移动相机）→ 仿真内给相机加“ToF 仿真”（鸭子真机头部就有 8×8 ToF，仿真里模拟它最贴近 sim2real）。
4. 稳定身份防跟丢：借鉴 TrackVLA++ 的 Target Identification Memory 思想做**轻量门控目标记忆**（遮挡后重识别），不必上 VLA。

#### 3.4 Agent 层（C 层，差异化做“身份+信任+记忆”，别做通用任务规划）
- 慢事件清单：召唤(挥手/语音/靠近站立)、指物(取物给主人)、陌生人进近距(触发警戒姿态/绕行)、主人久坐(安静陪伴)、被摸(开心反应)。
- 触发后用轻量 VLM 只消费“检测/ReID/pose 摘要 + 最近事件”，输出高层意图与文本决策链（看到谁→推断→做什么），**50Hz 运动仍由 B 层 RL 接管**（HUMA 已验证这套省算力且有效）。
- 记忆：Not-Forgotten 式跨会话 episodic memory（认识多久/常坐位置/喜好）+ 熟悉度连续量 → 影响 B 层奖励权重或行为参数 → “鸭子真的‘记得’主人”。
- 明确与 quackd 的差异：quackd=LLM 秒级挑技能做任务；DuckSoc=身份第一 + 连续社交运动学出来 + 信任分级 + 记忆个性化。

#### 3.5 评测（对齐 Follow-Bench 的“安全-舒适”双指标，但用鸭子物理）
- 安全：个人空间违规次数/时长、摔倒次数、与陌生人最近距离；
- 舒适/任务：召唤成功率与到位时间、跟随带内占比、orbit 是否保持距离、朝向人占比、能耗；
- 报告给“安全 vs 舒适”Pareto 曲线（对照手写状态机 L1 = baseline，展示 RL 版的提升）。

#### 3.6 交付物（Duck Together 投稿一套齐）
mjlab 新任务代码 + 训练好的 ONNX（命令级/关节级）+ `Microduck-Person-Ego` 数据集(HF) + 评测 JSONL/视频 + 帖子写清与 Follow-Bench/TPT-Bench/HUMA/quackd 的差异表。

### 备选 1（研究重、风险高）：E2E 第一视角视觉社交策略
head-cam 像素→CNN→关节动作；单卡 5090 训双足视觉策略高风险，建议放在 DuckSoc 之后作为论文延伸，Duck Together 演示不押注。

### 备选 2（演示/叙事线，工作量小）：认人+物归主 组合叙事
主人指某物→鸭子自主走到物→ground_pick/踢传给主人。用官方技能当“手”，人只当“身份+意图”。能快速出“家庭陪伴”Demo，和 DuckSoc 共用感知与记忆层。

### 备选 3（Agent 线）：长期个性化记忆陪伴鸭（Not-Forgotten 式）
重点做跨会话记忆/画像/信任演化，交互以轻量文本+行为变化呈现；不重运动学，但能撑起“认人→Agent”的故事线。

## 4. 建议路线（周级，全在云仿真）
- W1：人代理升级（纹理/体型/动作/室内场景）+ EGL 渲染数据管线 + 发布 1–2 万帧 `Microduck-Person-Ego` v0.1；人检测(YOLO11n)+SORT 替换真值，状态机不变复测 L1 指标。
- W2：身份层（ReID 或 CLIP 文本）+ 轻量目标记忆；`person_demo` 切 VisionPerception；跑通“召唤→跟主人→绕陌生人→回归”纯视觉版。
- W3：B 层 RL——先 `PersonFollow` 任务（proxemics 奖励 v1，真值人信息训练）→ 导 ONNX 替换手写状态机 → 对照 L1 指标出“安全-舒适”曲线。
- W4：加 `Summon`/`PersonOrbit` 任务与多人场景；感知噪声课程；整合 DuckSoc v1 评测集。
- W5（可选）：Agent 慢事件层（召唤/指物/久坐陪伴）+ 记忆模块；出组合 Demo 与对比表。
- 全程遵守：训练完关机、单卡为主、WANDB offline、发布走 ONNX+manifest(schema2)。

**鸭子适合做的不是“又一个认人 demo”，而是把“低视角身份感知 + proxemics 双足 RL 运动 + 条件式 Agent”串成一条可复现、可评测、可发布的全链路（DuckSoc）——每一层都有 2026 年文献锚点，但没有人把这套做到一只 25cm 的鸭子上。**
