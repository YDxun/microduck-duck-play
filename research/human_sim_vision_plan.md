# 人体仿真真实性升级 + 纯视觉手势识别（机器人算法工程师视角）

## 1. 更符合实际的人体仿真（有 Sim2Real 应用价值）

### 现状（L1）
- 人是“胶囊+mocap 运动学代理”：颜色/标签=身份，手臂预设角度=手势。
- 优点：快、可脚本、标签免费（GT）。
- 缺点：外观不真实 → 真实目标检测/姿态模型（YOLO/RTMPose 的 COCO person）认不出胶囊人；光照/材质不真实 → 视觉 Sim2Real 差距大。

### 升级选项（按实用性排序）
| 方案 | 做法 | 实用价值 | 成本/风险 |
|---|---|---|---|
| A. 拟人网格 + 关节化（推荐） | 引入 MuJoCo 可用的**人形网格模型**（mujoco_menagerie / SMPL-X / 人体 OBJ 低模），带衣服/肤色贴图；肢体用 mocap 关节摆姿势（我们已有 PoseManager 可扩展成关节骨架） | 视觉最接近真机：YOLO person / 姿态模型可直接用或仅需少量微调；ReID/手势才能谈 Sim2Real | 需下载/整理 mesh；手臂关节自由度增加 |
| B. 合成数据微调（本阶段采用） | 保留现有风格化人，用 **MuJoCo 渲染 + GT 自动标注** 生成大量第一视角图，微调轻量 **检测+姿态** 模型（YOLOv8n-pose） | 管线即“机器视觉闭环”本体：检测→关键点→手势；后续换真人也只需换数据 | 需跑通 数据生成→微调→ONNX→推理 链路 |
| C. 真人视频域（L3 再议） | 采集真人/开源姿态数据做域适应 | 真机部署最终形态 | 数据量大、本阶段不做 |

- 结论：先做 **B（合成数据微调出可部署模型，跑通视觉管线）**；外观真实性按 **A** 迭代（Menagerie/带贴图人模），为 RDK/真机打底。

## 2. 纯视觉手势识别设计（部署在“鸭子”侧）

### 管线（替代现在的 GT 关键点）
```
鸭子第一视角 RGB(320x240, 仰视)
 → YOLO-pose(微调) 出 person bbox + 上肢关键点(肩/肘/腕, 2D)
 → 身份：bbox 区域颜色外观描述子匹配(owner/stranger)  [后续可换 ReID]
 → 手势分类：由关键点 2D 几何规则(手相对肩的上/下/侧)判定
 → 只对 owner 且稳定0.6s 的手势 → 动作策略热切换(sit/pick/stand_up/roll)
```

### 关键点语义（COCO-17 子集，我们自定义可见）
我们只用可见的 10 点：nose=head、左右 shoulder=手臂根、左右 elbow≈中点、左右 wrist=手；其余 visibility=0。
手势定义为 2D 上可分（避免“前伸”在单目下的歧义）：
- right_up(右手上举) → sit
- both_down(双手下垂到低) → pick
- both_side(T字平举) → stand_up
- left_up(左手上举) → roll

### 实现步骤（本阶段）
1. 合成数据生成：随机化主人位置/朝向/手势 → 渲染 headcam RGB；用 GT(mocap)投影得到 bbox+关键点标签（免费、无人工）。
2. 微调：yolov8n-pose(预训练) 在合成集上 fine-tune（~100 张内，5090 数分钟）。
3. 导出 ONNX(imgsz=320) → duck_play 用 onnxruntime CPU 推理（模拟“鸭子端”部署；后续可换 RDK BPU/ONNX）。
4. 集成：vision 手势分类替换 pose.classify(GT)；保留 GT 作为“评测真值”做对比（消融：视觉 vs 真值）。

### 诚实预期
- 合成集很小，模型大概率过拟合到仿真场景；目标是“可运行闭环 Demo”，不是通用泛化；
- 后续要泛化 → 用更真实人体(A 方案)重采数据 + 域随机化 + 更多样本。
